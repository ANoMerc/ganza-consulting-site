# Ganza Consulting — сайт

Статический сайт (HTML/CSS/JS, без сборки), готов к деплою на GitHub Pages.

## Структура

```
index.html         — вся вёрстка и тексты (RU/EN)
css/style.css      — основные стили
css/builder.css     — стили конструктора проекта (баннер + модалка)
js/script.js        — переключатель языка и мобильное меню
js/builder.js        — конструктор проекта: движок оценки + UI визарда
```
